# USB-Uncensored-LLM для Windows

Персональный режим рассчитан на Ryzen 5 7430U с 16 ГБ RAM. Начните с 4-битной GGUF-модели на 2–4 млрд параметров и контекста 4096 токенов. Локальному движку задаётся контекст по умолчанию при запуске нового процесса Ollama. Если Ollama уже запущен, его настройки сохраняются.

1. При первой установке запустите `Windows\install.bat` и установите локальную модель.
2. Запустите `Windows\start-personal.bat` от обычного пользователя и откройте `http://localhost:3333`.
3. Для русского голосового ввода откройте страницу в браузере с Web Speech API, например Chrome, нажмите кнопку микрофона и разрешите доступ. Сервис распознавания может использовать интернет. Незнакомые голосовые фразы вставляются в поле чата, откуда их можно отредактировать и отправить.

Новые ответы автоматически озвучиваются по мере появления текста. После установки Миры русские фразы читает локальный голос **Ирина** в Piper. Для английских фраз или если Piper недоступен, приложение использует голоса браузера. Кнопка **🔊** рядом с микрофоном включает и выключает озвучивание.

Кнопка **Команда** открывает тот же список действий, что доступен голосом.

| Фраза | Действие |
| --- | --- |
| Покажи систему | Версия Windows и процессор |
| Открой проект | Папка проекта в Проводнике |
| Открой консоль | Интерактивный PowerShell в папке проекта |
| Покажи статус проекта | Ветка и изменения Git |
| Открой FirstVDS | Интерактивный SSH в отдельном окне |

Действия подтверждаются в браузере. Для деплоя Windows дополнительно показывает SSH-профиль и путь удалённого скрипта. Вывод действий отображается под полем ввода. В интерактивном PowerShell можно вводить собственные команды. Ассистент запускает перечисленные действия из своей панели.

## Голосовой диалог «Мира»

1. Один раз запустите `Windows\install-mira.bat`. Он загрузит Whisper Small для распознавания русской речи (190 МБ) и Piper с голосом Ирина (около 85 МБ). После установки оба работают локально. Модель Whisper Small обычно распознаёт точнее, но может отвечать медленнее, чем Whisper Base.
2. Запустите `Windows\start-personal.bat` и откройте чат в Chrome или Edge. Нажмите **Мира** рядом с микрофоном и разрешите доступ к нему.
3. Скажите **«Мира, привет»** или сначала **«Мира»**, затем дождитесь «Слушаю» и задайте вопрос. Ответ появляется в чате и озвучивается, если включена кнопка **🔊**.
4. Следующий вопрос можно задать без имени примерно в течение 20 секунд после озвучивания ответа. Во время ответа скажите **«Мира, стоп»**, чтобы прервать генерацию и озвучивание. Также распознаются варианты «Мира, стой» и «Мера, столб» во время ответа. Когда появится сообщение «Остановлено», задайте исправленный вопрос без имени. Режим Кодекса при этом сохраняется. Уже запущенный фоновый запрос Codex CLI может завершиться позже. Фраза **«Мира, закончи разговор»** между ответами возвращает ожидание имени. Повторное нажатие кнопки **Мира** или закрытие вкладки отключает микрофон.

Для обновления ранее установленной копии замените `Shared\FastChatUI.html`, `Shared\chat_server.py` и `Shared\personal.js`, скопируйте также `Shared\personal_whisper.py`, `Shared\personal_voice.py` и оба файла `Windows\install-mira.*`. Запустите установщик Миры в обновлённой папке. Существующий Ollama и его модели можно оставить на месте.

Если в терминале появилась ошибка `unexpected keyword argument 'interrupt'`, закройте Миру и скопируйте свежие `chat_server.py` и `personal_whisper.py` в папку `Shared` установленной копии. Переустанавливать Whisper или Piper не нужно.

## Облачные модели

Скопируйте `Shared\personal-models.example.json` в `Shared\personal-models.json`. Укажите идентификатор модели, адрес OpenAI-совместимого API (включая `/v1`, если его требует провайдер) и имя переменной окружения с ключом. Перед запуском задайте эту переменную вне репозитория. Профили с заданным ключом появятся в списке под префиксом `cloud/`.

Для облачных моделей доступен текстовый чат. При отправке браузер запрашивает разрешение перед передачей истории разговора провайдеру. API OpenAI оплачивается отдельно от ChatGPT. Для разделения локальных и облачных обсуждений используйте разные чаты.

## Спроси у Кодекса

В открытом чате нажмите **Мира** и скажите **«Мира, спроси у Кодекса: как в PowerShell узнать текущую папку?»**. Можно сначала сказать **«Мира, спроси у Кодекса»**, дождаться приглашения и продиктовать вопрос отдельной фразой. Кнопка станет **Мира · Кодекс**. Следующие голосовые вопросы продолжат идти Кодексу. После паузы можно снова обратиться «Мира» и задать вопрос. Чтобы переключиться обратно, скажите **«Мира, вернись в локальный режим»**. Ответ появится в чате с подписью **Кодекс · OpenAI** и прозвучит, если включено озвучивание.

Команда отправляет в OpenAI только текст отдельного вопроса. Предыдущие сообщения, файлы и аудиозапись остаются в вашей копии. Подключение требует интернета, ключа OpenAI API, доступа вашей учётной записи к модели и отдельно настроенной оплаты API. По умолчанию используется `gpt-5.3-codex`. При необходимости модель можно указать в переменной `USB_AI_CODEX_MODEL`.

Чтобы запустить чат с ключом, закройте предыдущий терминал Миры, запустите `Windows\start-with-codex.bat` и введите ключ OpenAI API в терминал. Ввод скрыт, ключ передаётся через окружение запущенного процесса. Если `OPENAI_API_KEY` уже задан в вашем окружении, подходит обычный запуск `start-personal.bat`. Команда обращается к OpenAI API независимо от текущей модели в чате.

## CRM Мариако через подписку ChatGPT

Для проверки соединения без микрофона введите в чат `/codex Как устроена эта CRM? Назови два файла проекта.` и нажмите Enter. Сообщение должно появиться с пометкой **Кодексу**.

1. В терминале Windows установите актуальный Codex CLI командой `winget install --id OpenAI.Codex -e`. После установки откройте новый терминал и выполните `codex login`. В браузере войдите в тот аккаунт ChatGPT, на котором оформлена подписка.
2. Подготовьте локальную папку [CRM Мариако](https://github.com/mariako2026i/mariako_crm). Подойдёт клон репозитория или распакованный ZIP из GitHub. Для загрузки приватного репозитория нужен вход в ваш аккаунт GitHub.
3. Закройте текущий сервер Миры, запустите `Windows\start-crm-codex.bat` и выберите папку CRM. В чате нажмите **Мира** и скажите **«Мира, спроси у Кодекса, как устроен этот проект»**.
4. Команда выполняет отдельный запрос Codex CLI с входом через ChatGPT и лимитами вашего тарифа. Codex может использовать нужные фрагменты файлов CRM на серверах OpenAI. Команда запускается в режиме чтения. Используйте копию проекта с исходным кодом без рабочих данных клиентов и файлов с секретами. Переписки и проекты из интерфейса ChatGPT сами не подгружаются.

Если обновляете установленную Миру, скопируйте с заменой `Shared\chat_server.py`, `Shared\cloud_models.py` и `Shared\personal.js`, а затем добавьте `Shared\personal_codex.py` и `Windows\start-crm-codex.bat`. Модели и голос заново скачивать не нужно. Если Codex CLI установлен нестандартно, можно указать полный путь к `codex.exe` через `USB_AI_CODEX_EXE`.

## Браузер, GitHub, почта и консоль

- **«Мира, открой YouTube»**, **«открой сайт example.com»** или **«открой CRM»** открывают страницу в браузере Windows. По умолчанию CRM открывается по адресу `http://localhost:3000`; адрес можно задать через `USB_AI_CRM_URL`.
- **«Мира, открой GitHub»** открывает репозиторий CRM. Для просмотра задач из чата установите GitHub CLI (`winget install --id GitHub.cli -e`), после установки откройте новый терминал и выполните `gh auth login`. Затем доступны **«покажи задачи GitHub»** и **«покажи задачу 12»**. Другой репозиторий можно указать через `USB_AI_GITHUB_REPO`.
- **«Мира, открой Gmail»**, **«открой Outlook»** и **«открой Яндекс Почту»** открывают выбранную почту. Для общей команды **«открой почту»** задайте `USB_AI_MAIL_URL`. Для входа используются обычные средства браузера.
- `/ps Get-Location` в чате подготавливает команду для PowerShell. `/ssh uptime` выполняет проверку через настроенный SSH. Перед запуском Windows покажет точную команду и цель. **«Подготовь команду из ответа для PowerShell»** извлекает один блок с языком `powershell` из последнего ответа в Мире. **«Подготовь команду из задачи для FirstVDS»** извлекает один блок `bash` из последней открытой задачи GitHub. Разрешены только встроенные диагностические команды. Скрипты и произвольные shell-команды через этот режим не запускаются.

## Подтверждение удаления

В голосовом режиме можно запросить перемещение одного файла выбранного проекта в карантин. Скажите **«Мира, подготовь удаление файла имя.txt»**. Проверьте показанный полный путь и в течение 30 секунд скажите **«да»** или **«нет»**. Каждому файлу нужен новый запрос и отдельное подтверждение. При согласии файл перемещается в папку проекта `.mira-trash`. Системные папки, каталоги, Git-метаданные и файлы вне проекта недоступны этой операции. В открытых вручную PowerShell и SSH действуют права вашего пользователя.

## FirstVDS

Включите клиент OpenSSH для Windows и настройте профиль в `%USERPROFILE%\.ssh\config`. Подключение Миры использует SSH-ключ и уже проверенный ключ хоста. Если для вашего тарифа доступна только веб-консоль, запросите параметры SSH у хостинга.

Из PowerShell запустите Миру с именем своего SSH-профиля:

```powershell
$env:USB_AI_SSH_ALIAS = 'my-firstvds'
.\Windows\start-crm-codex.bat
```

Затем скажите **«Мира, открой FirstVDS»**. Для команды `/ssh uptime` ввод и результаты проходят через SSH без веб-консоли. Автоматический запуск скрипта деплоя отключён, потому что скрипт может удалять файлы без отдельного вопроса про каждый файл.


## Пульт Миры для Android

1. Обновите установленную копию Миры. Скопируйте `Shared\chat_server.py`, `Shared\personal_actions.py`, новый `Shared\personal_mobile.py` и всю папку `Shared\mobile`. В папку `Windows` добавьте `start-mobile.bat`.
2. Установите Tailscale на Windows и Android. Войдите на обоих устройствах в одну частную сеть Tailscale. Ноутбук должен быть включён.
3. Закройте старое окно Миры, запустите `Windows\start-mobile.bat`, выберите папку CRM и оставьте терминал открытым. В терминале появится **Phone access code**. При каждом перезапуске он меняется.
4. Один раз откройте PowerShell и выполните `tailscale serve --bg http://127.0.0.1:3334`. Если PowerShell не находит Tailscale, используйте `& "$env:ProgramFiles\Tailscale\tailscale.exe" serve --bg http://127.0.0.1:3334`. При первом запуске Tailscale может попросить включить HTTPS для вашей сети.
5. Откройте на Android в Chrome адрес **HTTPS**, который выдал Tailscale, и введите код с ноутбука. Через меню Chrome можно добавить Миру на главный экран. Этот адрес доступен в вашей частной сети Tailscale. Используйте **Serve** для частного доступа.
6. Введите **«Мира, открой YouTube»** и нажмите **«Отправить»**. Вкладка откроется на ноутбуке. Для голосовой команды нажмите **«Микрофон»**, продиктуйте, снова нажмите кнопку, проверьте текст и отправьте. Whisper распознаёт запись на ноутбуке. Вопрос `/codex Как устроена CRM?` использует уже настроенный Codex на ноутбуке.

Аудио и текст связывают телефон с ноутбуком по частному туннелю. Обычные вопросы отвечает локальная модель. Запросы с явной командой **Кодекс** используют настроенное подключение Codex. Для чтения ответа есть кнопка **«Озвучить»**. В первом выпуске пульт управляет одним ноутбуком и поддерживает открытие страниц на нём, статус Git, сведения о системе и вопросы к моделям. Операции удаления, редактирование файлов и произвольные команды из Android недоступны. Обновление не меняет требование отдельного подтверждения удаления в режиме Windows.


### Проверка FirstVDS из чата

После подключения SSH-профиля в поле чата Миры можно по одной отправить следующие строки. Окно Windows покажет точную команду и SSH-профиль. После вашего подтверждения вывод появится под полем чата.

```text
/ssh whoami
/ssh docker compose version
/ssh docker ps -a
/ssh ss -lntp | grep -E ':(80|443)[[:space:]]'
```

Для первой настройки профиля `firstvds` подтвердите ключ хоста в обычном SSH-сеансе Windows, сверив отпечаток с данными сервера, и проверьте вход по ключу. В PowerShell команда `ssh -o BatchMode=yes firstvds whoami` должна вернуть имя пользователя без запроса пароля. Затем запустите Миру из того же PowerShell с `$env:USB_AI_SSH_ALIAS = 'firstvds'`. Для веб-консоли FirstVDS дополнительных настроек не требуется.
